GO GUIDE — TRAVEL PLANNING WEBSITE (FRONT-END DEMO)

FILES
- index.html : website structure and destination content
- style.css  : responsive visual design
- script.js  : filters, search, saved places, and trip board interactions

HOW TO RUN
1. Extract the ZIP file.
2. Open the go_guide_website folder.
3. Double-click index.html to open it in a modern browser.
4. Internet connection is recommended for Google Fonts and destination photos.

DEMO FEATURES
- Responsive landing page and navigation
- Destination cards for Ooty, Kodaikanal, Pondicherry, Madurai, Goa, and Manali
- Search and category filters
- Save/unsave destinations
- Add/remove destinations from a trip board
- Simple preference + budget-based sample suggestions
- Estimated starting budget for selected destinations

PROJECT NOTE
This is a front-end prototype for a final-year project presentation. It uses sample destination data and simple rule-based suggestions. It does not yet include a real AI/ML recommendation model, database, user authentication, live maps, or live travel prices. For the full academic project, these can be added with a backend and recommendation algorithm.
